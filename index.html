Great games are built through precise, iterative work.

GameAtlas evaluates the practical skills behind real-world, commercial game production. Across 91 tasks and eight disciplines, agents reconstruct assets, refine geometry, recover motion, and compose scenes—delivering editable files that fit the next step of a production workflow.

Rather than treating game creation as a single prompt, the benchmark measures whether agents can handle concrete production briefs, inspect feedback, and improve their work. Agents can make repeated submissions to hidden tests within each task’s budget. Evaluation follows executable criteria defined by game development experts, measuring the delivered artifacts without an LLM judge.

Expert-defined standards.
Deterministic evaluation.

Game production experts define the criteria for each task. We evaluate the agent’s actual deliverables—geometry, motion, scene layout, camera parameters, rendered images and layered artwork—using executable measurements, explicit tolerances and integrity checks. Each score is grounded in the submitted work and its recorded evidence, with no LLM judge.
